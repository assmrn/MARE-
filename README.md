# MARE

**Mission Anomaly Reasoning Engine**

MARE is a mission operations system for monitoring and reasoning over drone/mission telemetry.

It connects with PX4 and is being developed with support for mission planning, live telemetry, camera streams, and AI-based anomaly detection.

### Current Work

* Mission planning and waypoint management
* PX4 telemetry integration
* Camera stream monitoring
* AI-based detection and reasoning
* Mission status and system monitoring

This project is currently under development.
